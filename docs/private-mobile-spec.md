# 私有手机访问需求

2026-10-18，源于主人最新选择；替代此前等待备案的访问路线，不改变服务器计费方式。

- 保留杭州按量付费实例和现有私人数据；只供主人自己的设备连接，不开放公开网站入口。
- Android 换 Wi-Fi 或切换移动流量后可重新连接，使用稳定的私有 HTTPS 地址，不要求与服务器处于同一局域网。
- 使用 Tailscale。服务器与手机加入主人自己的网络；身份登录和设备绑定由主人完成，不索取账号密码或把设备授权密钥提交 Git。
- 仅在私有网络提供 Xinxin HTTPS 服务，使用 Serve，不启用公网 Funnel、出口节点、子网转发或 Tailscale SSH。网络加入资格与 Xinxin 主人登录是两层独立检查。
- API 继续只监听回环；前端静态网关只监听回环，私有 HTTPS 由 Tailscale 提供。上传上限、API 不缓存和 SSE 即时转发保持原契约；CORS 精确允许原生来源与实际私有 HTTPS 来源。
- 现有 read / workspace / full 权限、持久任务、上传幂等和事件回放继续工作；手机断开不停止云端任务，不宣称上传跨进程断点续传。
- 安卓可与 Clash 轮流启用，明确同一系统 VPN 通道不能同时运行这两个应用。主人表示偶尔使用 Clash，可以切换。
- 2核4GB资源限制、开机启动、备份和日志继续落地。新安装包使用既有私人发布签名；Git 不包含凭据、原始聊天、私人数据或签名密钥。
- 验证区分服务器内、另一个私有节点、无私有连接的公网和实体手机。真实手机换网、系统分享及键盘仍需主人测试，不能用服务内回环代替。
