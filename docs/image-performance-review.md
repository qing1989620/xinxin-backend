## Spec

初次审查发现两项P2，均已修复并独立复验：

- 同步HTTP路由下，大量冷请求可能占满AnyIO线程池，热图仍要等待。改为异步图片路由和单独编码执行器，合并相同图片的等待；ASGI真实接口回归在45个冷请求期间验证热图及时返回，取消一个请求后44个成功且仅编码一次。
- LA灰度透明PNG转换为RGB会丢失透明度。按alpha通道或调色板透明信息选择RGBA，增加灰度透明图片经旧inline展示接口的回归。

完整范围6c8efdd…fc36b53未发现剩余具体规格缺陷或范围扩张。独立验证失败共享与重试、编码器关闭、缓存上限、旧接口/原图下载契约及路径检查。审查使用隔离合成输入，没有访问正式图片、数据库或云端。
