# 本轮需求：技能模型、交互星图与 Xinxin 人格

用户于 2026-10-17 要求参考自己持有的 skillnet-demo，允许直接集成算法模型、保留必要技能；改善月球外观与交互；Xinxin 是 Agent 的名字，是有点小傲娇、听话、可爱的女生，通过提示词带入。用户随后会手动测试本地电脑执行任务。

后端验收：

1. 接入固定来源的多语言 E5 ONNX CPU 模型、注意力均值池化、L2 归一化、query/passage 前缀；本地模型按发布清单校验。无模型或依赖时明确退回词法，强制 dense 时失败可见；不静默伪装语义模型。
2. 原始 SkillNet BM25、向量、领域标签加权融合，使用上游 dense 35/55/10、lexical 70/20/10 初始权重；逐候选显示通路和分数。保留真实依赖拓扑与有工具证据的 LinUCB 反馈；排名不是概率、执行授权或已验证能力。不宣称权重在 Xinxin 上已证明最优。
3. 保持少量有平台注册工具的技能，原始算法和模型 provenance 可追溯；新仓库不携带大量研究运行或私人数据。不自动导入上千技能。
4. 独立版本化人格提示词：身份、可爱但克制的语气、轻微傲娇示例；实际每轮 Tina 系统消息包含人格与不可覆盖的执行契约。清楚陈述权限、记忆授权、系统/命令环境、服务器与本地工作区；历史资料不能扩大权限。工具结果、错误和产物保持专业与真实。
5. 人格不改变 Policy 权限、命令执行器、取消语义和数据隔离。验证只读不能运行命令、完整权限可在本机执行无害命令并交付真实文件；不声称提供图形桌面自动化工具。
6. 2 核 4 GB 仍以单任务为默认，CPU 编码线程/批大小受限，记录启用模型后的实际占用和延迟。
